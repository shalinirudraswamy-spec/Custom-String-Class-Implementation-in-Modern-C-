Custom String Class Implementation in Modern C++

📌 Project Overview

This project implements a custom "STRING" class in C++ using dynamic memory allocation and operator overloading. It demonstrates how string operations can be implemented without depending on the built-in string class, providing a better understanding of memory management and object-oriented programming.

🎯 Objectives

- Implement a custom string class.
- Understand dynamic memory allocation and deallocation.
- Use constructors and destructors.
- Implement operator overloading for string operations.
- Perform string manipulation without relying on built-in string functions.

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Dynamic Memory Allocation
- Operator Overloading

⚙️ Features

- Custom string storage and management.
- Dynamic memory allocation for string data.
- String operations using overloaded operators.
- Constructor and destructor implementation.
- Handling string objects through a user-defined class.
